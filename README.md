# Invest Wise Way

An AI-powered financial planning and wealth management platform built with Next.js and React. The platform provides interactive financial calculators to help users understand loans, manage debt, plan investments, track savings, and prepare for retirement.

## Features

- Modern, responsive financial planning dashboard
- Interactive financial calculators
- Loan and mortgage payment calculations
- Debt Snowball and Debt Avalanche strategies
- Investment and compound interest projections
- Retirement planning
- Budget planning using the 50/30/20 rule
- Net worth tracking
- Rent vs. Buy and Buy vs. Lease comparisons
- Interactive financial charts and visualizations
- Dark and light themes

## Financial Calculators

| Category | Calculators |
|---|---|
| Loans | Mortgage, Personal Loan, Auto Loan, Credit Card |
| Debt | Snowball, Avalanche |
| Investments | Investment, Compound Interest, Millionaire |
| Budgeting | 50/30/20, 20/10/4, Savings |
| Planning | Retirement, Net Worth |
| Housing | Rent vs Buy, Buy vs Lease |
